# 🔐 Nmap Fragmentation Scan (-f) — Evasion Technique

## 📌 Overview

This project demonstrates the use of **Nmap Fragmentation Scan (`-f`)**, an evasion technique used during penetration testing to bypass firewalls and intrusion detection/prevention systems (IDS/IPS).

Fragmentation splits packets into smaller pieces, making it harder for security devices to properly inspect traffic.

---

## 🧪 Command Used

```bash
nmap -f 192.168.56.1
```

---

## ⚙️ Command Explanation

| Component      | Description                                                    |
| -------------- | -------------------------------------------------------------- |
| `nmap`         | Network scanning and security auditing tool                    |
| `-f`           | Fragment packets into smaller IP fragments (evasion technique) |
| `192.168.56.1` | Target IP address                                              |

### 🔍 What `-f` Does

* Breaks packets into **8-byte fragments**
* Helps evade:

  * Firewalls
  * IDS/IPS systems
* Makes deep packet inspection more difficult

---

## 🔎 Result Analysis

### ❌ Host Status

* Target host appears **DOWN**
* No response received from ping probes

### ⚠️ Possible Reasons

* ICMP (ping) requests are **blocked by firewall**
* Target machine is **powered off**
* Network filtering rules are applied
* Fragmented packets may be **dropped by security devices**

### 💡 Important Observation

Even though fragmentation is used:

* It **does NOT guarantee** successful host discovery
* Some modern firewalls can detect and block fragmented packets

---

## 🚀 Recommended Next Step

Use `-Pn` to skip host discovery:

```bash
nmap -f -Pn 192.168.56.1
```

### ✔ Why Use `-Pn`?

* Treats host as **online**
* Bypasses ICMP blocking
* Continues scanning even if ping fails

---

## 🧠 Key Takeaways

* `-f` is useful for **evasion**, but:

  * Not always effective alone
* Combine techniques for better results:

  * `-f` → packet fragmentation
  * `-Pn` → skip host discovery
* Modern security systems may still:

  * Detect fragmentation
  * Drop suspicious packets

---

## 🏁 Conclusion

This scan highlights that:

* The target is **not responding to ping probes**
* Fragmentation alone is **insufficient in restricted environments**
* Combining evasion techniques improves scanning effectiveness
