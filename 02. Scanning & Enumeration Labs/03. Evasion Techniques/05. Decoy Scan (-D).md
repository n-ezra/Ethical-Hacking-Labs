# 🎭 Nmap Decoy Scan (-D) Analysis

## 📌 Overview

This project demonstrates the use of **Nmap Decoy Scan (`-D`)**, an evasion technique that hides the attacker's real IP address by mixing it with multiple fake (decoy) IPs.

This technique is commonly used in **penetration testing** to make tracking the real source of the scan more difficult.

---

## 🧪 Command Used

```bash
sudo nmap -D RND:10 192.168.56.1
```

---

## ⚙️ Command Explanation

| Component      | Description                            |
| -------------- | -------------------------------------- |
| `sudo`         | Runs the command with root privileges  |
| `nmap`         | Network scanning tool                  |
| `-D`           | Enables decoy scan                     |
| `RND:10`       | Generates 10 random decoy IP addresses |
| `192.168.56.1` | Target IP address                      |

## 🔎 Result Analysis

### ✅ Host Status

* Target host is **UP**
* Responding with a latency of **0.067 seconds**

---

### 🚫 Port Status

* All **1000 TCP ports are filtered**
* No open or closed ports detected

---

### ⚠️ What Does "Filtered" Mean?

* Packets are being:

  * Blocked by firewall
  * Dropped silently (no response)
* Nmap cannot determine if ports are open or closed

---

### 🔐 Key Observations

* 🔍 Decoy scan successfully executed with **10 fake IPs**
* 🛡️ Target system likely protected by:

  * Firewall
  * IDS/IPS
* 🚫 No ports exposed → strong network filtering

---

## 🚀 Why This Happens

Possible reasons for all ports being filtered:

* Firewall blocking incoming scan packets
* IDS/IPS dropping suspicious traffic
* Network ACLs restricting access
* Decoy packets triggering defensive mechanisms

---

## 🧠 Key Takeaways

* Decoy scan helps:

  * Hide attacker identity
  * Create noise in logs
* However:

  * It does **not guarantee port visibility**
  * Strong firewalls can block all probes

---

## 🏁 Conclusion

This scan shows that:

* The target is **alive but heavily protected**
* All ports are **filtered**, indicating strong firewall rules
* Decoy scanning increases stealth but:

  * Cannot bypass all security mechanisms alone
