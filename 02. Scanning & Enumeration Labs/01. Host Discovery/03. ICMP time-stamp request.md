# 📡 Nmap Host Discovery using ICMP Timestamp Request

## 🚀 Project Overview

This project demonstrates **advanced host discovery techniques using Nmap**, specifically leveraging **ICMP Timestamp Requests (`-PP`)** to identify live hosts in a network.

It highlights how attackers and security professionals can **bypass basic firewall restrictions** when traditional ping methods fail.

---

## 🎯 Objectives

* Perform **host discovery without port scanning**
* Use **ICMP Timestamp Requests** for detection
* Analyze **real Nmap output**
* Understand **firewall evasion basics**

---

## 🛠️ Tool Used

* **Nmap 7.95**

---

## 🔍 Command Used

```bash
nmap -sn -PP 192.168.56.1
```

---

## 🧠 Command Breakdown

### 🔹 `nmap`

Industry-standard tool for:

* Network discovery
* Security auditing
* Vulnerability assessment

---

### 🔹 `-sn` (Ping Scan)

* Disables port scanning
* Only checks whether host is **alive or not**
* Fast and efficient

👉 Used for: **Host Discovery Only**

---

### 🔹 `-PP` (ICMP Timestamp Request)

* Sends ICMP Timestamp packets instead of Echo Request
* Useful when:

  * Ping (ICMP Echo) is blocked
  * Firewall still allows timestamp responses

👉 Used for: **Firewall Evasion (Basic Level)**

---

### 🔹 Target: `192.168.56.1`

* Typically a **local VM adapter / gateway IP**

---


---

## ⚠️ Result Analysis

### ❌ Host Not Detected

Nmap reports:

> "Host seems down"

### 📌 Possible Reasons

* Host is actually **offline**
* ICMP Timestamp Requests are **blocked**
* Firewall filtering is active

---

### 💡 Important Insight

Even advanced ICMP techniques like `-PP` can fail if:

* Network is **strictly filtered**
* All ICMP traffic is disabled

---

## 🚀 Recommended Next Step

### 🔹 Skip Host Discovery

```bash
nmap -Pn 192.168.56.1
```

### ✅ Why?

* Treats host as **alive**
* Bypasses ICMP restrictions
* Allows **further scanning (ports/services)**

---

## 🧪 Practical Learning

| Technique     | Purpose              |
| ------------- | -------------------- |
| `-sn`         | Host discovery only  |
| `-PP`         | ICMP Timestamp probe |
| `-Pn`         | Skip host discovery  |
| `-PS` / `-PA` | TCP SYN/ACK ping     |

## 🔐 Real-World Use Case

In penetration testing:

* Many systems block **ICMP Echo (ping)**
* But allow **other ICMP types**
* Attackers use alternative probes like:

  * Timestamp (`-PP`)
  * TCP SYN (`-PS`)
  * ACK Ping (`-PA`)

---

## 📌 Key Takeaways

* `-sn` → Fast host discovery
* `-PP` → ICMP Timestamp technique
* No response ≠ Host down (may be filtered)
* Use `-Pn` to continue scanning
