# Nmap TCP ACK Ping (-PA) - Host Discovery

## 📌 Project Overview

This project demonstrates **host discovery using TCP ACK Ping (-PA) in Nmap**, a technique used to identify active hosts by sending TCP ACK packets to specified ports.

TCP ACK Ping is particularly useful in environments where **ICMP and SYN packets are filtered**, as it can bypass certain firewall rules.

## 📡 Technical Background

### 🔹 What is TCP ACK Ping?

TCP ACK Ping sends **ACK packets** to a target port to check if the host is alive.

### 🔹 How it Works:

* **RST response** → Host is **UP**
* **No response** → Host is **DOWN / Filtered**

💡 ACK packets do not establish a connection but help determine host availability.


## 🔥 Why ACK Ping Works Here

* Firewall allows ACK packets
* Target responds with **RST**, confirming availability
* Works even when SYN/ICMP may be blocked

---

## ⚖️ SYN vs ACK Ping

| Feature         | SYN Ping (`-PS`)  | ACK Ping (`-PA`) |
| --------------- | ----------------- | ---------------- |
| Packet Type     | SYN               | ACK              |
| Response        | SYN-ACK / RST     | RST only         |
| Firewall Bypass | Medium            | 🔥 High          |
| Use Case        | General discovery | Firewall evasion |
