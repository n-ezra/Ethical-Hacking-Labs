# Nmap ARP Scan - Host Discovery 

## 📌 Project Overview

This project demonstrates **host discovery using ARP requests via Nmap**, a highly reliable Layer 2 technique used to identify active hosts within a local network.

The scan targets a single host (`192.168.56.1`) and validates its availability using ARP-based probing, which is more effective than ICMP in LAN environments.

## 📡 Technical Background

### 🔹 What is ARP?

ARP (Address Resolution Protocol) maps an **IP address to a MAC address** within a local network.

### 🔹 Why ARP Scan?

* Operates at **Layer 2 (Data Link Layer)**
* Cannot be blocked like ICMP
* Provides accurate results in LAN

---

## ⚙️ Command Executed

```bash
sudo nmap -sn -PR 192.168.56.1
```

---

## 🔍 Command Breakdown

| Flag           | Description                          |
| -------------- | ------------------------------------ |
| `sudo`         | Required for raw packet transmission |
| `nmap`         | Network scanning tool                |
| `-sn`          | Host discovery only (no port scan)   |
| `-PR`          | ARP request scan                     |
| `192.168.56.1` | Target host                          |

## ⚖️ ARP vs ICMP Host Discovery

| Feature         | ARP Scan | ICMP Scan |
| --------------- | -------- | --------- |
| Layer           | Layer 2  | Layer 3   |
| Firewall Bypass | ✅ Yes    | ❌ No      |
| Accuracy        | ⭐ High   | Medium    |
| Speed           | ⚡ Fast   | Moderate  |
