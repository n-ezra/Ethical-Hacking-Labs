# 📡 TCP Connect Scan (-sT) – Nmap Detailed Analysis Report

## 🔍 Executive Summary

This project demonstrates a **TCP Connect Scan (`-sT`)** performed using Nmap against the target system `192.168.56.1`.

The objective of this scan is to identify open TCP ports and evaluate the network exposure of the target. The results indicate that all scanned ports are **filtered**, suggesting the presence of strong firewall rules or packet filtering mechanisms.

---

## 🔬 Scan Methodology

TCP Connect Scan works using the **full TCP 3-way handshake**:

1. SYN → Sent to target
2. SYN-ACK ← Received from target
3. ACK → Sent back (connection established)

* If connection succeeds → **Port is OPEN**
* If RST received → **Port is CLOSED**
* If no response → **Port is FILTERED**

## ❗ Understanding "Filtered" State

A port is marked as **filtered** when:

* No response is received from the target
* Scanner cannot determine port state

### Possible Reasons:

* Firewall blocking probes
* Packet filtering rules
* Silent packet dropping
