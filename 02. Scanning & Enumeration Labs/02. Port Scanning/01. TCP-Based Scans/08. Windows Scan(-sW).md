# Window Scan (-sW) using Nmap

## 📌 Overview

Window Scan (`-sW`) is a TCP-based scanning technique used in network reconnaissance to determine port states by analyzing the TCP window size in response packets.

This technique is less commonly used compared to SYN or ACK scans and depends on variations in TCP stack implementations across operating systems.

---

## ⚙️ Command Used

```bash
nmap -sW 192.168.56.1
```

---

## 🔍 Command Explanation

| Component      | Description             |
| -------------- | ----------------------- |
| `nmap`         | Network scanning tool   |
| `-sW`          | Enables TCP Window Scan |
| `192.168.56.1` | Target IP address       |

---

## 🧠 How Window Scan Works

* Sends TCP packets to target ports
* Observes TCP window size in responses
* Determines port state:

| Window Size | Port State |
| ----------- | ---------- |
| Non-zero    | Open       |
| Zero        | Closed     |

> Note: Results may vary depending on OS and firewall behavior.

## 🔎 Analysis

### ✅ Open Ports

* Multiple services are exposed:

  * FTP (21)
  * SSH (22)
  * Telnet (23)
  * WHOIS (43)

This indicates a system with many active services, increasing the attack surface.

---

### ⚠️ Filtered Port

* SMTP (25) is filtered

This suggests firewall rules are blocking or restricting access to this port.

---

### 🚨 Security Insights

* Telnet (23) is insecure (plaintext communication)
* Presence of legacy services (echo, chargen, daytime)
* High number of open ports indicates potential vulnerabilities

---

## ⚠️ Limitations

* Not reliable on modern systems
* Depends on TCP stack behavior
* Can produce false positives

---

## 🎯 Use Cases

* Firewall analysis
* Advanced scanning techniques
* Lab environments and security testing

---

## 🏁 Conclusion

Window Scan (`-sW`) provides insight into TCP window behavior and can help identify open ports in specific environments. However, due to its limitations, it should be used alongside other scanning techniques for accurate results.
