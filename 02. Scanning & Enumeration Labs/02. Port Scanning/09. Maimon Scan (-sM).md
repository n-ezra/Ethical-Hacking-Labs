# Maimon Scan (-sM) using Nmap

## 📌 Overview

Maimon Scan (`-sM`) is an advanced TCP scanning technique used in network reconnaissance. It sends packets with **FIN + ACK flags** to identify port states based on how the target system responds.

This technique is effective only on certain systems (mainly BSD-based) and is often used for **stealth scanning**.

---

## ⚙️ Command Used

```bash id="cmd001"
nmap -sM 192.168.56.1
```

---

## 🔍 Command Explanation

| Component      | Description           |
| -------------- | --------------------- |
| `nmap`         | Network scanning tool |
| `-sM`          | Enables Maimon Scan   |
| `192.168.56.1` | Target IP address     |

---

## 🧠 How Maimon Scan Works

* Sends TCP packets with **FIN + ACK flags**
* Expected behavior:

  * **Closed ports → RST response**
  * **Open ports → No response**

### 📊 Interpretation

| Response     | Port State      |
| ------------ | --------------- |
| No response  | Open / Filtered |
| RST response | Closed          |

## ⚠️ Limitations Observed

* Maimon scan is **ineffective on this target**
* Modern systems (Linux/Windows) do not respond as expected
* Results are ambiguous (`open|filtered`)
