# IP Protocol Scan (-sO) using Nmap

## 📌 Overview

IP Protocol Scan (`-sO`) is an advanced Nmap technique used to identify which IP protocols (TCP, UDP, ICMP, etc.) are supported by a target system.

Unlike traditional scans, this method analyzes **protocol numbers instead of ports**.

---

## ⚙️ Command Used

```bash id="cmd01"
sudo nmap -sO 192.168.56.1
```

---

## 🔍 Command Explanation

| Component      | Description                      |
| -------------- | -------------------------------- |
| `sudo`         | Required for raw packet scanning |
| `nmap`         | Network scanning tool            |
| `-sO`          | Enables IP Protocol Scan         |
| `192.168.56.1` | Target IP address                |

---

## 🧠 How IP Protocol Scan Works

* Sends packets using different **IP protocol numbers (0–255)**
* Waits for responses:

  * **Response received → Protocol supported**
  * **No response → Open / Filtered**
  * **ICMP unreachable → Closed**

## 🔎 Analysis

### ⚠️ Key Observation

* All **256 IP protocols → open|filtered**
* No protocol returned a definitive response

---

### 🧠 Interpretation

This indicates:

* Target system is **not responding to protocol probes**
* Possible reasons:

  * Firewall blocking unusual protocol traffic
  * System silently dropping packets
  * ICMP responses disabled

---

### 🚨 Security Insights

* Strong indication of **network filtering or firewall protection**
* Protocol-level reconnaissance is **restricted**
* Difficult to identify supported protocols due to lack of responses

---

## ⚠️ Limitations Observed

* Results are **inconclusive**
* Cannot differentiate between:

  * Supported protocols ❓
  * Filtered protocols ❓
* Modern systems often block such scans

---

## 🎯 Use Cases

* Protocol-level attack surface analysis
* Firewall rule testing
* Advanced penetration testing

---

## 🏁 Conclusion

The IP Protocol Scan (`-sO`) did not return any definitive results, with all protocols marked as `open|filtered`. This suggests that the target system is likely protected by a firewall or configured to ignore protocol-based probes.
