# 📡 Nmap SCTP COOKIE-ECHO Scan (-sZ)

## 🔍 Overview

The **SCTP COOKIE-ECHO Scan (`-sZ`)** is an advanced Nmap scanning technique used to analyze **SCTP (Stream Control Transmission Protocol)** services by sending a COOKIE-ECHO chunk instead of a full handshake.

This scan is useful in **telecommunication networks and specialized infrastructures** where SCTP is implemented.

---

## 🎯 Objective

* Discover SCTP-enabled services on the target
* Analyze firewall behavior for SCTP traffic
* Perform stealthy reconnaissance using SCTP protocol

---

## ⚙️ Command Used

```bash
sudo nmap -sZ 127.0.0.1
```

---

## 🧠 Command Breakdown

| Component   | Description                            |
| ----------- | -------------------------------------- |
| `sudo`      | Required for raw packet-level scanning |
| `nmap`      | Network scanning tool                  |
| `-sZ`       | SCTP COOKIE-ECHO Scan                  |
| `127.0.0.1` | Localhost (loopback address)           |

## 📊 Result Analysis

* Target: **localhost (127.0.0.1)**
* Host is **UP and reachable**
* Latency: **~0.0000070 seconds (very fast, local system)**

---

### 🚫 Port Status

* Total scanned ports: **52 (SCTP)**
* All ports are **FILTERED**
* No SCTP services responded

---

### 🔐 Meaning of "proto-unreach"

* The system responded with **Protocol Unreachable**
* Indicates:

  * SCTP protocol is **not supported or disabled**
  * OS is rejecting SCTP packets
  * No SCTP stack/service is running

---

## 🛡️ Security Interpretation

* System is **not running SCTP services**
* Strong indication that:

  * SCTP is **disabled at OS level**
  * Kernel does not support SCTP OR module not loaded
* No exposure to SCTP-based attacks

---

## ⚠️ Limitations

* SCTP scans are **environment-specific**
* Results may not apply to typical TCP/UDP services
* Filtered results do not guarantee port state accuracy
