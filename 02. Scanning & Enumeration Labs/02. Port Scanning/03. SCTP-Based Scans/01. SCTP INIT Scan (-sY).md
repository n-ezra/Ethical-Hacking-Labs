# 📡 Nmap SCTP INIT Scan (-sY)

## 🔍 Overview

The **SCTP INIT Scan (`-sY`)** is an advanced Nmap scanning technique used to discover open ports and services running over the **SCTP (Stream Control Transmission Protocol)**.

Unlike TCP/UDP, SCTP is mainly used in **telecom and signaling networks**, making this scan useful in specialized environments.

---

## 🎯 Objective

* Identify SCTP-based services on a target system
* Analyze firewall behavior for SCTP traffic
* Perform advanced network reconnaissance

---

## ⚙️ Command Used

```bash
sudo nmap -sY 192.168.22.128
```

---

## 🧠 Command Breakdown

| Component        | Description                            |
| ---------------- | -------------------------------------- |
| `sudo`           | Required for raw packet-level scanning |
| `nmap`           | Network scanning tool                  |
| `-sY`            | SCTP INIT Scan (half-open SCTP scan)   |
| `192.168.22.128` | Target IP address                      |

## 📊 Result Analysis

### ✅ Host Status

* The target system is **UP and reachable**
* Latency: **0.059 seconds**

### 🚫 Port Status

* Total scanned ports: **52 (SCTP)**
* All ports are **FILTERED**
* No response received from any port

### 🔐 What "Filtered" Means

Filtered ports indicate:

* Packets are **blocked or dropped**
* No response is sent back to the scanner

Possible reasons:

* Firewall rules blocking SCTP traffic
* Intrusion Detection/Prevention Systems (IDS/IPS)
* No SCTP service running on the target

---

## 🛡️ Security Interpretation

* The system is **well-protected against SCTP scans**
* No SCTP services are exposed externally
* Firewall is likely configured to **drop SCTP packets silently**

---

## ⚠️ Limitations of SCTP Scan

* SCTP is **not widely used** in general systems
* Filtered ports do **not confirm open/closed state**
* Results may be inconclusive without deeper analysis
