# 🔍 Host Tool – DNS Reconnaissance & Footprinting

## 📖 Overview

The **Host tool** is a lightweight yet powerful command-line utility used for performing **DNS lookups**. It is commonly utilized during the **reconnaissance phase** of ethical hacking to gather publicly available information about a target domain.

This project demonstrates how the `host` command can be used for **DNS enumeration**, helping identify critical infrastructure components such as IP addresses, mail servers, and name servers.

---

## 🎯 Objectives

* Perform domain-to-IP resolution
* Conduct reverse DNS lookups
* Extract DNS records (A, MX, NS, TXT)
* Understand DNS infrastructure of target systems
* Support passive reconnaissance activities
