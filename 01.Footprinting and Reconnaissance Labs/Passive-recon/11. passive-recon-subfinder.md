# 🔎 Subfinder – Subdomain Enumeration & Passive Reconnaissance

## 📖 Overview

**Subfinder** is a fast and powerful **subdomain discovery tool** developed by ProjectDiscovery. It is widely used in **passive reconnaissance** to enumerate subdomains of a target domain using multiple OSINT sources.

This project demonstrates how to use Subfinder to discover subdomains and analyze a target’s external attack surface.

---

## 🎯 Objectives

* Perform passive subdomain enumeration
* Discover hidden and publicly exposed subdomains
* Map target domain infrastructure
* Support bug bounty & penetration testing workflows

## ⚙️ Installation

### ✅ Using Go

```bash
go install github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
```

### ✅ Verify Installation

```bash
subfinder -version
```

---

## 🚀 Usage

### 🔹 Basic Command

```bash
subfinder -d vulnweb.com
```
