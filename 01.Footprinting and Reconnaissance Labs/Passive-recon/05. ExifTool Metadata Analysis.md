## 📌 Project Overview

This project demonstrates the use of **ExifTool** to extract and analyze metadata from image files. Metadata analysis is a fundamental skill in **Open Source Intelligence (OSINT)**, **Passive Reconnaissance**, and **Digital Forensics** because hidden information inside files can reveal useful details about file creation, editing history, software used, and technical characteristics.

The objective of this project is to perform metadata extraction on a JPEG image and document the findings using industry-standard methodology.

---

## 🎯 Objectives

* Extract metadata from image files.
* Identify image properties and file attributes.
* Analyze embedded metadata.
* Understand metadata exposure risks.
* Demonstrate passive reconnaissance techniques.
* Document findings professionally for cybersecurity portfolios.

# 🚨 Security Implications

Metadata can unintentionally expose sensitive information.

Potentially exposed data may include:

* GPS Coordinates
* Device Information
* Operating System Details
* Author Names
* Usernames
* Software Versions
* Timestamps
* Internal Project Information

Attackers frequently analyze metadata during reconnaissance phases to gather intelligence about a target.
