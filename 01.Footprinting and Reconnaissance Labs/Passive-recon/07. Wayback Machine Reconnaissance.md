# 🌐 Wayback Machine Reconnaissance (Real-Time Practical Analysis)

## 📖 Overview

The **Wayback Machine (Internet Archive)** is a critical **passive reconnaissance tool** used to analyze historical versions of web applications. It enables security professionals to uncover **hidden endpoints, deprecated features, and exposed data** by inspecting archived snapshots.

This project demonstrates a **real-world analysis using Google.com snapshots**, showcasing how applications evolve over time and how this can be leveraged in **penetration testing & bug bounty hunting**.

---

## 🎯 Objectives

* Analyze **historical snapshots of a target**
* Identify **changes in application structure**
* Discover **deprecated/hidden functionalities**
* Understand **attack surface evolution**
* Support **advanced reconnaissance workflows**

---

## ⚙️ Methodology

### 1️⃣ Identify Target

```bash id="ex1"
google.com
```

---

### 2️⃣ Explore Archive Timeline

* Enter domain in Wayback Machine
* Analyze:

  * Year-wise growth
  * Snapshot frequency
  * Technology evolution

---

### 3️⃣ Inspect Historical Snapshots

Focus on:

* Old login pages
* Admin panels
* Deprecated APIs
* Backup/config files

---

### 4️⃣ Extract URLs (Automation)

#### 🔸 waybackurls

```bash id="ex2"
echo "google.com" | waybackurls > urls.txt
```

#### 🔸 gau

```bash id="ex3"
gau google.com > urls.txt
```

---

### 5️⃣ Filter Interesting Data

```bash id="ex4"
grep -E "\.env|\.json|\.bak|admin|api" urls.txt
```

## ⚠️ Limitations

* Not all data is archived
* Some snapshots may be incomplete
* Requires manual validation
* Possibility of false positives

## 🧠 Best Practices
