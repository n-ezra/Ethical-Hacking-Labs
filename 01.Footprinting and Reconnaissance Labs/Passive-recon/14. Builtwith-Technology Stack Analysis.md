# 🔍 Technology Stack Analysis using BuiltWith (VulnWeb Case Study)

## 📌 Overview

BuiltWith is a web-based reconnaissance tool used to identify the technologies used by a target website. It plays a key role in passive reconnaissance by revealing the tech stack without directly interacting with the target.

---

## 🎯 Objective

* Identify technologies used by the target
* Understand infrastructure and hosting
* Assist in vulnerability mapping

---

## 🌐 Target Analyzed

```
vulnweb.com
```

---

## 🧰 Tool Used

* BuiltWith (Web-based Technology Profiler)

## 📊 Security Insights

* Use of **jQuery** → Check for outdated versions
* **PHP backend** → Version enumeration needed
* **AWS infrastructure** → Misconfigurations possible (S3 buckets)
* **Nginx server** → Check for misconfigurations

---

## ⚠️ Limitations

* BuiltWith may not detect hidden technologies
* Version details are not always visible

---

## ⚖️ Ethical Considerations

* Perform only on authorized targets
* Do not misuse collected data

---

## 🚀 Conclusion

BuiltWith provides valuable insights into the target's technology stack, helping security researchers identify potential attack surfaces and plan further testing.
