# 🔍 theHarvester – OSINT Reconnaissance Tool

## 📌 Overview

**theHarvester** is a powerful open-source intelligence (OSINT) tool used for gathering information about a target domain from publicly available sources. It plays a crucial role in the **footprinting & reconnaissance phase** of ethical hacking.

---

## 🎯 Objective

* Perform passive information gathering
* Identify emails, subdomains, and hosts
* Map the target attack surface
* Collect OSINT data from multiple sources

## 🛠️ Installation

### Kali Linux (Pre-installed)

```bash
theHarvester -h
```

### Install Manually

```bash
sudo apt update
sudo apt install theharvester
```

### Install from GitHub

```bash
git clone https://github.com/laramies/theHarvester.git
cd theHarvester
pip3 install -r requirements.txt
```

---

## 🚀 Usage

### Basic Command

```bash
theharvester -d example.com -b bing
```

### Explanation

* `-d` → Target domain
* `-b` → Data source (bing used in this example)

---

## 🧪 Practical Demonstration

### Command Used

```bash
theHarvester -d example.com -l 500 -b bing

```
