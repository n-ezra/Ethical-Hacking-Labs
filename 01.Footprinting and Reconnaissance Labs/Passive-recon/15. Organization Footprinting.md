# 🏢 Organization Footprinting (VulnWeb Case Study)

## 📌 Overview

Organization Footprinting is a passive reconnaissance technique used to gather detailed information about a target organization's digital footprint, including domains, infrastructure, technologies, and ownership.

This case study demonstrates footprinting using **vulnweb.com**.

---

## 🎯 Objective

* Identify organization behind the target
* Discover associated assets
* Map infrastructure and technologies
* Understand attack surface

---

## 📊 Security Insights

* Multiple subdomains → expanded attack surface
* Use of PHP → potential outdated version risks
* Cloud hosting → possible misconfigurations
* Public test environment → intentionally vulnerable

---

## ⚠️ Risks Identified

* Misconfigured subdomains
* Exposed endpoints
* Weak configurations in test environments

---

## ⚖️ Ethical Considerations

* This target is intentionally vulnerable (safe for learning)
* Always perform recon on authorized targets
* Follow responsible disclosure practices

---

## 🚀 Conclusion

Organization Footprinting provides a comprehensive understanding of the target ecosystem. In this case, VulnWeb demonstrates how multiple assets, technologies, and infrastructure components contribute to the overall attack surface.
