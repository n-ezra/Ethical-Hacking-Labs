# 🌐 DNS Enumeration using DNSDumpster (Real-World OSINT Recon)

## 📌 Project Overview

This project demonstrates **DNS Enumeration using DNSDumpster**, a passive reconnaissance tool used to extract publicly available DNS intelligence about a target domain.

The scan was performed on a test target:

> **Target Domain:** `vulnweb.com`

This activity simulates the **initial reconnaissance phase of a penetration test**, where an attacker gathers information without directly interacting with the target system.

---

## 🎯 Objectives

* Perform **passive reconnaissance (OSINT)**
* Enumerate DNS records of the target domain
* Identify:

  * Subdomains
  * IP addresses
  * Mail servers (MX)
  * Name servers (NS)
* Understand external attack surface

---

## 🛠️ Tool Used

* **DNSDumpster** – Web-based DNS reconnaissance tool

---

## 🧠 What is DNS Enumeration?

DNS Enumeration is the process of discovering DNS-related information such as:

* Subdomains
* DNS records
* Server details

This helps security professionals identify **potential entry points** into a system.

---

## ⚙️ Execution Steps

1. Navigate to DNSDumpster
2. Enter target domain: `vulnweb.com`
3. Complete CAPTCHA verification
4. Click on **Start Test**
5. Analyze generated results:

   * Host records (A)
   * MX records
   * NS records
   * TXT records
6. Download report & capture evidence
